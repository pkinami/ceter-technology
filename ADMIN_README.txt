CETER Admin

Core workflow:

1. Upload the Product Import Template from /admin/import.
2. Fix any validation errors shown in the preview.
3. Import valid rows. Products are created as DRAFT.
4. Review drafts in /admin/products.
5. Add or replace images manually when needed.
6. Publish products when ready.
7. Customers see PUBLISHED products in the catalogue.

Admin sections:

- Dashboard
- Products
- Categories
- Brands
- Imports
- Media
- Orders
- Settings

Product statuses:

- DRAFT
- PUBLISHED
- ARCHIVED

Images:

- Product Image URL from Excel is saved directly.
- Manual uploads are managed in admin.
- Product images come from upload or imported URLs.
